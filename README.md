# Canopy IIIF template has moved

This template repository moved from `canopy-iiif/template` to [`nulib-ds/canopy-template`](https://github.com/nulib-ds/canopy-template). Its demo site now lives at **https://nulib-ds.github.io/canopy-template/**.

This repository exists only to redirect every URL that was previously hosted at `https://canopy-iiif.github.io/template/*` to its new location, so existing links and bookmarks keep working.
